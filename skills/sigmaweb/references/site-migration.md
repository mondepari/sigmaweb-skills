# Перенос и обновление сайта клиента

Задача: у клиента есть старый сайт (донор). Нужно сделать в SigmaWeb новую, улучшенную версию —
с его контактами, описанием, услугами/товарами и фото, но с современной структурой и текстами.

## 0. Подготовка (делает владелец аккаунта SigmaWeb)

1. В студии создать сайт (подходящий шаблон ниши или пустой) нужного типа: лендинг, многостраничник
   или магазин.
2. Сайт → Интеграции → «ИИ-агенты (MCP)» → ключ «Чтение и правка черновика» → подключить к агенту.

## 1. Прочитать донора

Откройте главную и ключевые страницы старого сайта (WebFetch / браузер) и выпишите:

- название, чем занимается бизнес, город/район, отличия — для `set_business_profile` (1–3 предложения);
- контакты: телефоны, email, адрес, часы работы, соцсети и мессенджеры, реквизиты (если есть);
- услуги / товары с ценами, описаниями и фото;
- блоки доверия: отзывы (только реальные, с сайта), сертификаты, команда, кейсы, FAQ;
- фото: `<img src>`, самое крупное из `srcset`, фоновые картинки, `og:image`. Пропускайте иконки,
  счётчики, баннеры чужих сервисов, логотипы платёжных систем;
- логотип (картинка) — для шапки.

## 2. План владельцу

Коротко: какие страницы и разделы будут, какие фото переносите, что улучшите. Спросите о спорном
(устаревшие цены, закрытые филиалы). Дальше работайте без лишних вопросов.

## 3. Сборка

1. `get_site` — тип сайта и страницы; `get_page home` — что уже стоит (шаблон).
2. `set_business_profile { about }`.
3. `update_site_info { part: "contacts", patch: { phone, phones, email, address, hours, socials } }`,
   шапка (`header`: logo / logoImage, menu, cta) и подвал (`footer`). Сначала `get_site_info`.
4. `import_media { folder: "Со старого сайта", items: [{ url, alt }] }` — пачками до 20. Запомните
   соответствие «что на фото → новый url». Ошибки по отдельным фото не критичны — пропустите.
5. Страницы из блоков **библиотеки** (`page_gaps` подскажет стандарт для типа сайта):
   первый экран (HERO) → услуги/товары (SERVICES, PRICE_LIST, PRODUCT_GRID…) → почему мы →
   галерея/кейсы → отзывы → FAQ → форма заявки / запись → контакты (CONTACTS, MAP).
   Блоки шаблона, которые подходят, — обновите (`update_block`), лишние — уберите только если
   они явно не нужны (`delete_block`), недостающие — добавьте (`add_block`).
6. Многостраничник: `create_page` для разделов донора (услуги, о компании, контакты…), затем блоки.
   Пункты меню — `update_site_info { part: "header", patch: { menu: [...] } }`.
7. Своих фото не хватает для раздела — `generate_photos` (с согласия владельца: платно).
8. `set_page_seo` для каждой страницы: title ≤ 70, description ≤ 160, с городом и услугой.

## 4. Качество

- Тексты: короче и конкретнее донора, выгоды клиента, ясные призывы. Факты — только с донора.
- Не копируйте устаревшее (старые акции, «© 2015»), чужие водяные знаки.
- Проверьте `page_gaps` ещё раз; не больше ~30 блоков на странице.
- Отчёт владельцу: что перенесено, что улучшено, чего не хватило (например, нет фото команды) и что
  проверить в редакторе перед публикацией.
